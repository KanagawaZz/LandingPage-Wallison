# LandingPage-Wallison

Landing page profissional para Wallison Prado, desenvolvida com Vite, JavaScript ES Modules, HTML semântico e CSS responsivo.

## Requisitos

- Node.js compatível com a versão atual do Vite
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/components/`: seções e elementos da interface
- `src/data/`: conteúdo editável e configurações do site
- `src/styles/`: tokens, estilos globais e responsividade
- `src/utils/`: utilitários de SEO e link do WhatsApp
- `public/images/`: imagens públicas, incluindo a imagem de Têmis

Consulte `docs/README.md` e `docs/ARQUITETURA.md` para mais informações.
