# Wallison Prado — Landing Page

Landing page desenvolvida em Vite + JavaScript ES Modules com arquitetura modular e conteúdo separado em `src/data/`.

## Estrutura principal

- `src/main.js` — composição da página
- `src/components/` — blocos visuais e seções
- `src/data/` — textos e configurações editáveis
- `src/styles/` — tokens, base visual e responsividade
- `src/utils/` — utilitários de WhatsApp e SEO

## Como rodar

```bash
npm install
npm run dev
```

## Como construir

```bash
npm run build
```

## Observações

Os dados ainda não confirmados foram mantidos como campos editáveis em `src/data/`, permitindo a substituição posterior sem mexer na arquitetura da interface.
